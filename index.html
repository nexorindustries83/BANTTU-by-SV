Manual de Administración

☁️ MODO NUBE: Si has configurado Firebase, los cambios se guardarán automáticamente para todos los usuarios. Si no, seguirán guardándose solo en este dispositivo.

1. Acceso: Usa el candado (🔒) en el pie de página. Clave inicial: admin123.

2. Gestión de Productos:

  • Crear: Botón "Nuevo Producto". Llena nombre, precio y stock por talla.
  • Editar: Botón (✏️) en la lista. Ajusta precios o stock manualmente si vendes en físico.
  • Eliminar: Botón (🗑️). ¡Cuidado! No se puede deshacer.

3. Imágenes: Puedes subir fotos desde tu celular; el sistema las optimiza automáticamente para que no pesen mucho.

4. Pedidos: El cliente envía el pedido a tu WhatsApp. El stock en la web se descuenta automáticamente cuando el cliente finaliza el proceso en la página.

5. Copia de Seguridad: Usa "Backup" para descargar tus datos. Usa "Restaurar" para cargar un archivo guardado anteriormente si cambias de dispositivo.

6. Publicar Cambios: Tus cambios son locales. Para que el mundo los vea: Usa "Copiar Código", pega el texto en tu archivo index.html (reemplazando defaultProducts) y sube el archivo a Netlify.

⚠️ Importante: Los datos se guardan en este dispositivo. Evita "Borrar datos de navegación" para no perder el inventario. ¡Usa la función de Backup regularmente!
